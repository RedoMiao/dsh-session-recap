# 项目笔记模板（Obsidian）

> 用法：把下面整份文件丢给 agent，让它按"模板正文"写笔记；"执行说明"那一节它自己看，写完删掉。

- 产出：
  - 【本地文件路径，含尺寸/时长】
  - 【平台发布：YYYY-MM-DD HH:mm，标题「…」，链接（没有就写"未导出"）】

## 执行说明（给 agent，写完删掉这一节）

### A. 写之前

1. 先在 vault 里找目标文件夹：`项目经历 / <年.月> / <日期 + 项目名>`。用户可能拼错（例如 `Cluade`），按"日期 + 近似名"匹配，**不要新建同名目录**。
2. 文件名用 `<项目名> · <副标题>.md`，与同目录其他笔记保持一致。
3. 先读一篇同目录旧笔记，照它的 frontmatter 写法和详略程度来，不要自己另起一套。

### B. 抓平台数据（只读）

**B1. 抖音**

- 地址：`https://creator.douyin.com/creator-micro/content/manage`
- **最大的坑**：浏览器里已经开着的那个"创作者中心"标签，可能停在**扫码登录页**，即使账号其实是登录状态。不要据此判断"没登录"。
- 正确做法：**新开一个标签**访问上面的地址，再判断一次。新标签会带上已有会话。
- **不要走 CDP**：Chrome 136+ 不允许在默认配置目录开 `--remote-debugging-port`；复制一份配置目录也拿不到登录态（cookie 是 app-bound 加密的）。这条路上我已经浪费过 20 分钟，直接跳过。
- 可靠做法：
  1. 聚焦 Chrome 窗口（AppActivate）；
  2. 整屏截图；
  3. 用滚轮滚动作品列表；
  4. 按"标题 + 发布时间"定位那一条；
  5. 从卡片上直接读数字。
- 卡片上的列：播放 / 点赞 / 评论 / 分享 / 收藏 / 完播率 / 2 秒跳出率 / 吸粉。

**B2. 小红书**

- 地址：`https://creator.xiaohongshu.com/creator/notemanage`（或创作服务平台 → 笔记管理）。
- 同样只读、同样用"截图 + 滚动"读，不点进详情页。

**B3. 怎么判断"真的没登录"**

| 看到什么 | 结论 |
|---|---|
| 二维码 / 手机号输入框 / "扫码登录" | 未登录 |
| "内容管理""作品 (N)" / 笔记列表 | 已登录 |

未登录就**停下来告诉用户**"需要一个已登录的窗口"，不要尝试扫码、不要碰密码。

### C. 记录规则

- 必须写**统计时间**（到分钟）。
- 数字照抄，不估算、不四舍五入；读不清就截图问用户。
- 链接拿不到就写"未导出"，不要编造。
- 平台的"播放"对应模板里的"浏览"，在括号里注明。

### D. 别做的事

- 不要重启用户的浏览器（会丢标签页，我干过）。
- 不要复制或导出 cookie / 登录数据。
- 不要为了调试去改系统设置、装插件、开远程调试。
- 不要点赞、评论、编辑、删除、导出数据。
- 不要在用户没要求的情况下换筛选/排序之外的页面设置。

### E. 写完后自检

- [ ] frontmatter 五个字段都有，`时间` 与实际一致
- [ ] `平台数据` 有统计时间，且数字与页面一致
- [ ] 没有把"未导出链接"写成假链接
- [ ] 踩坑条目是"现象 → 根因 → 解法 → 规则"，不是流水账
- [ ] 文件写进了用户指定的文件夹，没有多建目录
